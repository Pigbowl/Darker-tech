## 问题分析
当前`resetAllCardsAndLines`函数在进入和退出选中模式时都会被调用，用户希望将其拆分为两个独立函数，分别负责普通模式和选中模式的排布，并根据状态和用户操作判断执行哪个函数。

## 解决方案
1. **拆分函数**：将`resetAllCardsAndLines`拆分为两个独立函数
2. **明确职责**：
   - 普通模式函数：负责卡片的随机排布和样式设置
   - 选中模式函数：负责相关卡片的高亮和有序排布
3. **统一样式管理**：将所有卡片样式设置（背景、阴影、边框、字体颜色大小）整合到这两个函数中

## 具体修改

### 1. 创建普通模式排布函数
```javascript
function resetToNormalMode() {
    // 重置所有卡片到普通模式状态
    document.querySelectorAll('#buble-container > div').forEach(card => {
        // 移除所有选中模式相关样式
        card.classList.remove(...);
        
        // 设置普通模式样式
        card.classList.add('bg-transparent', 'border-transparent', 'opacity-60', 'scale-95', 'z-10');
        
        // 设置字体样式
        const titleEl = card.querySelector('div:first-child');
        const descEl = card.querySelector('div:last-child');
        const cardType = card.dataset.type;
        const sizeConfig = nodeSizeConfig[cardType];
        
        // 根据层级设置字体颜色和大小
        let fontColor;
        switch(cardType) {
            case 'top': fontColor = '#8B0000'; break;
            case 'mid': fontColor = '#0000FF'; break;
            case 'bottom': fontColor = '#FF0000'; break;
            default: fontColor = '#FFFFFF';
        }
        titleEl.style.color = fontColor;
        titleEl.style.fontSize = sizeConfig.fontSize;
        descEl.style.color = '#FFFFFF';
        
        // 重新生成随机位置
        const newPosition = getRandomPosition(cardType);
        card.style.left = `${newPosition.x}px`;
        card.style.top = `${newPosition.y}px`;
        
        // 更新位置数据
        const id = card.name;
        cardPositions[id].x = newPosition.x;
        cardPositions[id].y = newPosition.y;
        originalPositions[id] = { x: newPosition.x, y: newPosition.y };
    });
    
    // 重置连接线
    requestAnimationFrame(drawConnections);
    
    // 更新状态
    selectedCardId = null;
    relatedCardIds.clear();
    isSelectionMode = false;
    updateConnectionInfoPanel();
}
```

### 2. 创建选中模式排布函数
```javascript
function resetToSelectionMode() {
    // 重置所有卡片到初始状态，为进入选中模式做准备
    document.querySelectorAll('#buble-container > div').forEach(card => {
        // 移除所有特殊样式
        card.classList.remove(...);
        
        // 设置基础样式
        card.classList.add('bg-transparent', 'border-transparent', 'opacity-60', 'scale-95', 'z-10');
        
        // 重置字体样式
        const titleEl = card.querySelector('div:first-child');
        const descEl = card.querySelector('div:last-child');
        titleEl.classList.remove('text-glow');
        
        // 恢复原始位置
        const id = card.name;
        if (originalPositions[id]) {
            card.style.left = `${originalPositions[id].x}px`;
            card.style.top = `${originalPositions[id].y}px`;
            cardPositions[id].x = originalPositions[id].x;
            cardPositions[id].y = originalPositions[id].y;
        }
    });
}
```

### 3. 修改调用逻辑
在`selectCard`函数中根据当前状态判断调用哪个函数：
```javascript
function selectCard(cardId, cardesc) {
    if (selectedCardId === cardId) {
        // 退出选中模式，调用普通模式排布
        resetToNormalMode();
        return;
    }
    
    // 进入选中模式，先重置为初始状态
    resetToSelectionMode();
    
    // 后续选中模式逻辑...
    selectedCardId = cardId;
    // ... 其他选中模式处理
}
```

### 4. 统一样式管理
- 将所有卡片样式设置整合到这两个函数中
- 确保普通模式下卡片背景、阴影、边框为透明
- 根据层级设置字体颜色和大小
- 选中模式下根据卡片类型设置相应样式

## 修改效果
- **进入选中模式**：调用`resetToSelectionMode`重置卡片状态，然后执行选中逻辑
- **退出选中模式**：调用`resetToNormalMode`重新随机排布卡片，恢复普通模式样式
- **样式统一管理**：所有卡片样式设置都集中在这两个函数中，便于维护
- **状态清晰**：根据不同状态执行不同的排布逻辑，避免混淆

## 预期结果
- 普通模式：卡片随机分布，无阴影，根据层级显示不同颜色
- 选中模式：相关卡片高亮显示，有序排列，显示阴影
- 模式切换流畅，样式统一管理
- 避免多次选择后卡片重叠问题
